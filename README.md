# Замер скорости скачивания

`measure_speed.py` — консольный замер скорости по одному адресу. Скрипт делает **10 GET-запросов строго по очереди**, каждый раз дожидается последнего байта ответа и печатает среднее время запроса, общий объём и скорость скачивания.

Нужен Python 3.9 или новее. Внешние пакеты не ставятся: только стандартная библиотека.

## Запуск

Адрес передаётся аргументом. Кавычки нужны, чтобы оболочка не разрезала URL по `&` и `?`.

PowerShell:

```powershell
py -3 measure_speed.py "https://speed.cloudflare.com/__down?bytes=1000000"
```

Linux и macOS:

```bash
python3 measure_speed.py "https://speed.cloudflare.com/__down?bytes=1000000"
```

Параметр `bytes` у Cloudflare — точный размер ответа. Для более тяжёлого файла поставьте, например, `10000000`.

Тот же запуск по тяжёлой картинке (около 14 МиБ):

```powershell
py -3 measure_speed.py "https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg"
```

Если в консоли Windows вместо кириллицы видны кракозябры:

```powershell
py -3 -X utf8 measure_speed.py "https://speed.cloudflare.com/__down?bytes=1000000"
```

Справка: `py -3 measure_speed.py --help`.

Строка результата появляется только после того, как ответ этого запроса прочитан целиком. Следующий запрос до этого не начинается.

### Параметры

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| `url` | — | абсолютный адрес `http://` или `https://` |
| `-n`, `--requests` | `10` | сколько запросов сделать подряд |
| `-t`, `--timeout` | `60` | таймаут сокета в секундах: на установку соединения и на каждую операцию чтения |

Коды возврата:

| Код | Когда |
| --- | --- |
| `0` | все запросы дочитаны, скорость напечатана |
| `2` | неверный аргумент: схема не http/https, число запросов меньше 1, таймаут не положительный |
| `1` | обрыв, таймаут или HTTP-ошибка. Скорость по неполному набору не печатается |

Ответ `429` или `503` значит, что сервер просит не так часто. Скрипт читает `Retry-After` и повторяет тот же запрос. Короткую паузу вроде 1 с он увеличивает до 5 с: серия быстрых повторов у Википедии превращается в бан. Если сервер просит ждать долго (у этой картинки бывает 600 с, то есть 10 минут), скрипт ждёт этот срок один раз и пишет, сколько осталось. Пауза и отклонённые попытки в среднее время и скорость не входят. После такого ограничения перед следующим запросом есть ещё 5 с паузы.

## Что входит в замер

Каждый запрос открывает своё соединение. Время запроса — от старта вызова до последнего байта тела: DNS, TCP, TLS для https, заголовки и тело. Закрытие сокета в цифру не входит.

Объём — это сколько байт тела реально прочитано, а не поле `Content-Length` и не служебный трафик TCP/IP. Редиректы проходятся, их время входит в замер. Заголовки `Cache-Control: no-cache` и `Pragma: no-cache` просят не отдавать кэш; промежуточный узел всё равно может ответить из кэша.

Вывод округляется для чтения. Среднее и скорость считаются по полным значениям таймера, не по уже округлённым строкам.

## Единицы

| Величина | Единица | Определение |
| --- | --- | --- |
| Время | секунда, `с` | `time.perf_counter()`, на экране три знака после запятой |
| Объём | `Б`, `КиБ`, `МиБ`, `ГиБ` | двоичные: 1 КиБ = 1024 Б, 1 МиБ = 1024² Б, 1 ГиБ = 1024³ Б. В итоге дополнительно печатается точное число байт |
| Скорость | **`Мбит/с`** | основная единица, десятичные мегабиты как у провайдера: 1 Мбит/с = 1 000 000 бит/с |
| Скорость, дополнительно | `МиБ/с` | (байты / 1024²) / секунды |

Формулы по всем успешным запросам:

- среднее время = (t₁ + … + tₙ) / n
- общий объём = b₁ + … + bₙ
- общее время = t₁ + … + tₙ
- скорость, Мбит/с = (общий объём × 8) / общее время / 1 000 000

Скорость — это сумма байт, делённая на сумму времён, а не среднее арифметическое скоростей отдельных запросов. При одинаковом размере ответов оба способа совпадают.

## Пример

Десять запросов по 1 000 000 байт. Цифры скорости зависят от канала; объём на этом URL фиксированный, по нему удобно проверить формулу.

```text
Адрес: https://speed.cloudflare.com/__down?bytes=1000000
Запросов: 10

 №       время         объём        скорость
 1     1.446 с     976.6 КиБ     5.53 Мбит/с
 2     1.480 с     976.6 КиБ     5.41 Мбит/с
 3     1.322 с     976.6 КиБ     6.05 Мбит/с
 4     1.333 с     976.6 КиБ     6.00 Мбит/с
 5     1.368 с     976.6 КиБ     5.85 Мбит/с
 6     1.371 с     976.6 КиБ     5.84 Мбит/с
 7     1.440 с     976.6 КиБ     5.56 Мбит/с
 8     1.675 с     976.6 КиБ     4.77 Мбит/с
 9     1.360 с     976.6 КиБ     5.88 Мбит/с
10     1.414 с     976.6 КиБ     5.66 Мбит/с

Среднее время запроса  1.421 с
Общий объём            9.54 МиБ (10 000 000 байтов)
Общее время            14.209 с
Скорость скачивания    5.63 Мбит/с (0.67 МиБ/с)
```

Проверка руками: среднее 14.209 / 10 = 1.421 с. Скорость 10 000 000 × 8 / 14.209 / 1 000 000 ≈ 5.63 Мбит/с.

## Проверка без интернета

Локальные тесты поднимают свой HTTP-сервер и проверяют три вещи: тело читается до конца (ответ больше одного куска), запросы не пересекаются во времени, при ошибке скрипт останавливается и не печатает скорость.

```powershell
py -3 -m unittest test_measure_speed.py
```
